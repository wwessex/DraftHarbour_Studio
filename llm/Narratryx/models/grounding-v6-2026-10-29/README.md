# Narratryx grounding-v6 research adapter

A fresh-base local learning-rate comparison, not an application upgrade. The [research prerelease](https://github.com/wwessex/DraftHarbour_Studio/releases/tag/narratryx-grounding-v6-2026-10-29) contains the actual MLX LoRA adapter, exact configuration, base/hash manifest, model card, upstream Apache-2.0 licence and modification notice. The base weights and runtime are not included; use the exact base revision/hashes in [manifest.json](manifest.json). This is not a standalone Windows/Mac installer.

The trial uses the same 80 records, 9,085 supervised tokens, explicit prompt masks, seed 42, 2,048-token context and twenty-update recipe as grounding-v5. Only learning rate changes from 5e-6 to 5e-5. Prose targets remain source-derived; no generated literary teaching targets are added. All 64 evaluation cases were previously exposed, even though role names retain the original v5 cohort names. Repeated diagnostic results are not independent literary-quality evidence. Human quality ratings remain zero; this adapter is not selected or promoted.

All twenty updates and 192 responses completed without errors or truncation; reported peak MLX memory was 7.17 GB. Development loss fell to 1.0563, but clock accuracy fell from v5's 6/24 to 5/24, all eight exact repairs stayed correct, and prose length results were mixed. All four transfer analyses still incorrectly infer premature lateness; three of four transfer rewrites repeat the input unchanged. **Do not promote this candidate.** Lower loss does not establish literary improvement.

Download the ZIP and `SHA256SUMS`, verify the ZIP checksum and embedded adapter/configuration hashes, and keep this adapter in a separate directory from the selected craft profile. Full execution details and limitations are in the [trial report](../../docs/grounding-training-v6-2026-10-29.md). The [earlier archive](../experimental-2026-10-29/README.md) preserves the craft and grounding-v5 weights separately.

No books, source scans, training/evaluation records, manuscripts, credentials or reviewer keys are uploaded. The user's 29 October 2026 instruction authorises model publication; frozen prior rights records are unchanged and are not represented as prior publication approvals. Source evidence concerns selected expired original prose and GB/US training uses, not blanket worldwide legal certification. The pinned base identifies Apache-2.0, with full upstream licence and modification attribution included. No source-provider or upstream endorsement is claimed.

Applications and their selected model remain unchanged. Apple Silicon MLX evidence does not establish Windows/Linux inference, distribution readiness or Muse equivalence. Ordinary users do not need local training.
