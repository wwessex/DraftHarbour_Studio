# Multi-chapter context comparison

The synthetic project spans three chapters. It tracks a traded token, a signal that does not grant boarding, two conditional signalling rules, and a hidden identity. Write, Continue and Rewrite tasks use the same current passage. The project is evaluation-only.

A Vitest capture exercised the shared Story Bible selector with the fixture's queries and scene facts. Every designated required fact appeared. The private identity and mismatched day rule were absent throughout. The night rule appeared only in the two requests marked night. The irrelevant market entry appeared in all three captures. This is a small selection check where the entries fit in the budget.

Craft completed six fresh requests. Each pair received the same brief and passage, with either minimal hand-selected facts or the captured references. The local comparison uses a common wrapper around these inputs. The capture represents the Story Bible portion of the request, while the production editor can also add continuity, blueprint and chapter context.

| Task | Hand-selected facts | Shared selector |
|---|---|---|
| Continue | Fits the length and leaves boarding open, but describes magical warmth and never visibly raises the ribbon. | Raises the ribbon and leaves boarding open, but applies the lamp's low position to the ribbon. |
| Write | Fits the length, yet mostly watches the boat and treats the cabin lamp as the signal. | Raises the ribbon but switches into the ferryman's perspective and adds what he sees and feels. |
| Rewrite | Changes the prose and keeps the source of the movement unclear. | Changes the prose and keeps the source of the movement unclear. |

The required facts were present in these captures. Neither context condition consistently translated them into correct action. This fixture also has a weakness for Write: the night rule describes holding a lamp, but the only clearly established lamp is aboard the boat. A stronger test would give Ada a lamp explicitly and distinguish her signal from the observed cabin lamp.

The selector test covers shared code used by web/PWA, Windows/Linux Tauri and Capacitor iOS. Native macOS context assembly was inspected separately in source. It builds its own references and continuity warnings. No platform app was built or run for this research comparison. The inference run was a standalone MLX process on Apple Silicon.
