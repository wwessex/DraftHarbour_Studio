# Whole-manuscript Chat, approved edits and refreshed desktop build

Implemented and checked on 25 October 2026. This report supersedes the excerpt-only shared Chat behavior described in the earlier local Analysis/Chat report.

## Author workflow

- Open **AI Chat** from the visible desktop button, Tools menu, quick switcher or mobile AI Chat tab. Chat can inspect every chapter/scene, including inactive chapters and passages beyond the old 4,000-character excerpt limit. Requests read the manuscript in bounded, overlapping parts and combine the evidence for discussion. Progress identifies the section being read; Stop cancels the request. Large manuscripts therefore take multiple local model calls rather than fitting into one prompt.
- For manuscript changes, enable **Request edit proposals**, describe the requested changes and send. Discussion mode cannot produce actionable edits. Edit mode returns verified, chapter-labelled before/after previews, not an automatic manuscript update. Approve/Accept or Reject controls are explicit. Shared Chat groups verified changes into one proposal per chapter; native local-provider Chat does the same. Apple Foundation Models retains its project tools, with tool edits validated and grouped against complete chapter snapshots.
- Every proposed original span must match the reviewed source. Missing, repeated or overlapping ambiguous anchors are rejected rather than guessed. Approval requires the chapter to retain its complete source snapshot; editing another part of that chapter invalidates the proposal. A recovery snapshot is saved before applying an approved change. Shared approval rechecks the source after asynchronous snapshot persistence and blocks mutation if snapshot creation fails. Save failures after approval retain the draft and recovery/save-queue safeguards and are reported explicitly.
- Edit acknowledgements are generated from the verified proposal count, rather than trusting generated prose to describe what was changed. The author remains responsible for assessing the model's suggestions.
- Native macOS has permanently labelled **AI Chat** and **AI Suggestions** controls above the document, so they are not hidden in the macOS toolbar overflow menu. Chat opens in its own sidebar. Suggestions opens its tool panel; its quick/custom requests now remain previews until Apply Suggestion or Discard. Existing passage writing actions retain their own approval controls.
- Native Chat, Suggestions and Analysis honor the previously selected On this computer mode using the app-managed local runtime. Existing configured local providers remain available. No runtime endpoint or private runtime credential is exposed to the shared renderer. No cloud fallback, model download, training, credential import or app default change was introduced.

Shared Chat conversation/proposal state remains scoped to the current project session. Native threads/proposals/revision logs retain their existing portable extension format. No project-format or database schema migration was needed. Source Markdown and unmodified surrounding text are preserved. Story Bible inference references continue through the controlled-context filter; conditional facts without author-supplied state remain excluded.
