# Copyedit and controlled Bible references — 25 October 2026

The shared writing toolbar and independent native Mac toolbar now expose **Copyedit** alongside Write, Rewrite and Continue. Copyedit asks for an object containing up to 32 exact `before`/`after` edits. Every original anchor must occur once; overlapping, missing, ambiguous or malformed proposals are rejected. The app constructs a plain corrected preview and retains the existing explicit acceptance, source-snapshot checks, undo and revision workflow. Creative Rewrite is unchanged. A model returning ordinary prose to Copyedit produces a verification error, never a guessed replacement. No minimum output word count is imposed.

Story Bible entries support optional portable `aiAccess` metadata: `hidden`, `hiddenFields`, and field-specific `conditions`. Field identifiers are `body`, `aliases`, `validity`, or `field:<custom name>`. Conditions use comma-separated exact `name=value` facts. Authors control these under **AI reference access** in the entry editor; newly named custom fields start hidden. Existing files without metadata retain their prior behaviour. Current policy travels through project exports, backups, imports and revision history. Restoring a revision also restores its access policy.

The writing assistant accepts optional Scene facts, held only in the composer and cleared on chapter/section changes or close. A conditional field is omitted unless every supplied condition matches. Other AI tools supply no scene state and conservatively omit conditional fields. Hidden fields are removed before relevance ranking. Names and aliases match Unicode word boundaries. Structured canon shadows matching legacy names/aliases even when hidden or archived. Links in shared writing references name only visible selected cards. Native chat/search build an inference-only sanitised index. Author Markdown/JSON exports still retain author data, including facts hidden from AI.

These controls govern structured reference selection, not global redaction. A fact copied into manuscript prose, summaries, another card or another context source may still be sent from that source. Titles remain visible unless the whole entry is hidden. Free-text validity dates are never interpreted automatically. Selection remains lexical and bounded by characters, not a complete semantic saliency engine or tokenizer guarantee.
